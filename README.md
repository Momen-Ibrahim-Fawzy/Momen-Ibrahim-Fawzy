### 💼 What I build

- **AI-agent platform for the General Court of Audit (GCA).** Configurable LLM pipelines that filter,
  semantically classify and extract the legal hierarchy (regulation → article → paragraph) from about
  130K audit-feedback records.
- **"Copilot of agents" for Al Rajhi Capital.** It orchestrates a RAG knowledge base and a robo-advisory
  engine (signals, forecasts, portfolio optimiser) through LLM tool calling, with streamed charts and
  human-in-the-loop trade proposals.
- **Esaal, a bilingual voice and text assistant.** Speech-to-text on NVIDIA Triton, Arabic TTS with
  diacritisation, streaming LLM chat, hierarchical document parsing with Milvus retrieval, and
  conversation analytics.
- **Email intelligence.** 19 microservices (tone, topics, semantic search, summaries, action items,
  reply suggestions) on a quantised LLM server, built on about 245K emails.
- **Natural-language analytics.** Text-to-SQL agents with conversation memory, query disambiguation and
  automatic charts, including a bilingual trade-analytics assistant for GAFT.
- **EjaNabd.** Contactless health assessment: 30+ vital metrics from a 30-second webcam scan (rPPG,
  MediaPipe) plus an LLM health assistant.
